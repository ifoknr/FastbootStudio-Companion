# Notes for Claude sessions on this repository

## Release notes: Arabic and English
Every release's notes are written in both languages. The `## vX.Y.Z` section of `CHANGELOG.md`, which is the GitHub release body and the Telegram post, holds:

1. the Arabic part (Gulf dialect, short bullets);
2. a line `**English**`;
3. the same in English.

Keep the section short: the Telegram caption fits about 760 characters of notes.

## Commits and pull requests
They show IFOKNR only (`.claude/settings.json`): no Co-Authored-By or session lines in
commit messages or pull request descriptions.
